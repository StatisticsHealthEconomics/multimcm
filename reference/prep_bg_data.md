# Prepare background data

Background hazard point values.

## Usage

``` r
prep_bg_data(input_data, bg_varname, formula_cure, event_type, suffix = TRUE)
```

## Arguments

- input_data:

  Data frame

- bg_varname:

  String for background variable name

- formula_cure:

  Parsed formula list

- event_type:

  String specifying event type

- suffix:

  Logical indicating whether to append suffix

## Value

A list with background data
